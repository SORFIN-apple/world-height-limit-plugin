# World Height Limit 1.2.1

- Fixed sleeping not skipping the night on Minecraft 26.1–26.3. The generated Overworld dimension now specifies the vanilla world clock.
- No configuration changes are required.

Verified on Purpur 26.2: sleeping advances the world clock to morning, and high-altitude block placement still works.

After replacing the 1.2.0 JAR, start the server once to regenerate the datapack. Then fully stop and start it again to load the corrected dimension settings.
