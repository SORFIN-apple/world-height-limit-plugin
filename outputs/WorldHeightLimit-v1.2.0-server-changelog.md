# World Height Limit 1.2.0

- Added server plugin builds for Minecraft 1.17–26.3, grouped by version range.
- Added a dedicated build for Minecraft 1.20.5–1.20.6.
- Added bStats support for anonymous server statistics.

After installing the plugin or changing the target height, fully restart the server. On a fresh installation, start the server once to generate the datapack, then stop and start it again to apply the new height.
