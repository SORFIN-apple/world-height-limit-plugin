# World Height Limit 1.2.0

### Expanded server support

World Height Limit now has server plugin builds for Minecraft **1.17 through 26.3**. Downloads are organized by Minecraft version and server platform, so you can pick the JAR that matches your server.

Minecraft **1.20.5–1.20.6** has its own build to handle the changes in those versions.

### Server statistics

Added **bStats** integration for anonymous server statistics. Server owners can disable it in `plugins/bStats/config.yml`.

### Before you build higher

On a fresh installation, start the server once to generate the datapack, then **fully stop and start it again** to apply the new world height. A full restart is also required after changing the configured height.
