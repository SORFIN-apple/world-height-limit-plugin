# World Height Limit 1.18.x

## Status

The `project/` directory contains a buildable server plugin for Minecraft 1.18–1.18.2.
Paper 1.18, 1.18.1 and 1.18.2 passed the isolated real-player placement, denial and persistence test at Y=2000. The 1.18 Paper build was marked ALPHA by Paper's archive; an official Mojang 1.18 server JAR with verified SHA-1 was supplied because the old Paper downloader returned a truncated file.
